# QuantileRegressionEpi

This repository contains Quarto source files, R code, figures, tables, and synthetic data associated with the methodological monograph:

**Quantile regression of gestational age and preterm birth for epidemiology research**

**Lawrence McCandless** is Professor, Faculty of Health Sciences, Simon Fraser University, 8888 University Drive, Burnaby BC V5A 1S6, Canada.

E-mail: `lmccandl@sfu.ca`

## Website

The rendered Quarto website is available at:

https://lawrence-mccandless.github.io/QuantileRegressionEpi/

## Repository Contents

* `index.qmd` and associated `.qmd` files contain the Quarto source documents.
* `data/` contains synthetic datasets used for examples and demonstrations.
* `figures/` contains figures used in the manuscript and website.
* `tables/` contains tables and supplementary outputs.
* `docs/` contains the rendered website generated by Quarto and used by GitHub Pages.

## Synthetic Dataset

The repository includes a synthetic version of the 1958 UK Perinatal Mortality Survey (PMS) dataset used for demonstrations in the monograph. The synthetic dataset is intended for methodological illustration only and does not reproduce the original individual-level records.

## Reproducibility

The analyses were conducted using:

* R
* Quarto
* cmdstanr
* quantreg

To render the website locally:

```r
quarto::quarto_render()
```

or from a terminal:

```bash
quarto render
```

## GitHub Pages

The website is deployed using GitHub Pages from the `docs/` directory.
